# Incidental source-search exposure — 2026-10-06

During provider documentation discovery, a batched search using textual site:
constraints returned off-domain 2026 issuer-delisting snippets. A follow-up search
with explicit official domain filters also returned an indexed unbounded current
listing endpoint containing 2025–2026 listing metadata. These are out-of-envelope
financial/security observations; therefore this phase cannot claim zero exposure.

Neither result was opened as a data endpoint, saved into a research panel, used to
choose a source based on financial outcomes, nor used in feature/model/policy choices.
No model/OOS/holdout evaluation occurred. No financial values or issuer identities
from the accidental results are reproduced here.

Cause: search engines expand results beyond intended documentation and can surface
cached data endpoints. Textual site constraints and domain filters alone are not a
sufficient isolation mechanism. Containment: stop broad/provider search queries;
use known documentation URLs and explicit historical data requests only. Do not
follow unbounded endpoint links. Retrospective holdout remains NOT RUN / NOT PRISTINE.

Earlier incident reports remain untouched. This record is disclosure, not a request
to redesign methodology or reclassify the excluded period as pristine.

Follow-up: the explicitly opened EODHD corporate-actions documentation also
contained contemporary financial examples (including a 2026 event date) in the
returned page excerpt. Documentation URLs alone therefore do not isolate dates.
Those examples were not used or transcribed into acquisition evidence. Stop live
provider-document discovery for this phase; use the already inspected interface
contracts and explicit pre-cutoff sample endpoints. New deliberate financial
requests remain bounded; incidental exposure is recorded separately from those
requests and is not reported as zero.
