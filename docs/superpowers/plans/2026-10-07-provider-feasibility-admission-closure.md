## Task 1 — Evidence and provider decisions

Review official documentation in priority order: universe, terminal economics,
prices/actions, fundamentals, macro, FX, context/events. Preserve earlier evidence.
Produce one authoritative provider matrix plus compact, dated claim references.
Only bounded observation requests are eligible; document incidental exposure.
No credentials, data purchases, model execution or methodology changes.
Commit the evidence and decisions after checking references and diff whitespace.

## Task 2 — Coverage contract and proof decision

Write failing artifact-contract tests for complete frozen feature coverage,
mandatory US/EU families, fallback order, explicit classifications, evidence
references and phase-scoped access counters. Run RED before creating artifacts.
Create machine-readable MVRP and fallback/coverage artifacts, companion reports,
and updated status. Reuse existing raw evidence only within its proven scope.
Attempt proof assembly only if all necessary joins and rights are supportable;
otherwise record each unrun quality/leakage check as BLOCKED, never PASS.
Run focused tests GREEN, then commit. No new model architecture is required.

## Task 3 — Review, verification and checkpoint

Run full pytest, compileall and git diff --check. Obtain independent provider/
methodology, PIT/leakage and code-quality reviews. Correct material findings.
Verify frozen files unchanged, public diff free of raw/secret/binary artifacts.
Record exact review scope, commit and package source/history/test evidence only.
Checkpoint excludes private raw records. STOP for human review.

## Interfaces and review focus

Task 1 claim IDs feed Task 2 provider rows and feature coverage. Documentation
feasibility never promotes actual admission or quality tier. Task 2 phase receipt
must coexist with prior receipts, not overwrite them. Task 3 reviews the blocked
conclusion if no real proof panel exists, not hypothetical positive data quality.
Review source semantics vs commercial promises, latest-only metadata, terminal
assumptions, calendar known-at, licensing, global missingness and false PASS risks.
