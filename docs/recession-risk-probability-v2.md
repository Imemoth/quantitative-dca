# Recession Probability V2 — deferred research design

No probability model, target winner or calibration method is selected here.
Candidate future outcomes include 3M/6M/12M growth stress, NBER recession, negative
GDP states and credit-stress states. Their economic meanings and label availability
are different; retrospective recession dating must not become a contemporaneous input.

A future mandate should separately define each label's reference period, publication
clock, vintage policy, region, missingness, class balance and maturity/purge rules.
NBER labels describe the US; euro-area and non-euro EU jurisdictions need independently
justified target definitions. Do not assume one region's label or rule transfers.

Use constrained baselines and challengers, train-local preprocessing and calibration,
chronological nested evaluation, predetermined metrics and an experiment ledger.
Evaluate calibration/Brier skill, decision relevance, false alerts, episode persistence,
revision sensitivity and robust uncertainty under rare events and correlated horizons.
Do not select a winner from the already exposed retrospective period.

No such research is run in the current phase. The current data confidence measures
evidence usability, not event probability. V2 must earn incremental usefulness before
any integration, and cannot modify frozen V1 retrospectively.
