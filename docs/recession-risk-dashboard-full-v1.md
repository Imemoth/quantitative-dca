# Full Recession Risk Dashboard V1 — deferred design

The current core is a read-only evidence and state scaffold. It is not a validated
recession signal and must not delay standalone DCA validation without justification.

A later, separately authorized full dashboard needs admitted regional macro panels,
reviewed economic definitions and predeclared descriptive rules. Reuse the core's
versioned diagnostic inputs, immutable evidence references and explicit jurisdiction.
No new input automatically enters the frozen DCA feature set.

Historical diagnostics must replay vintage-correct EOD snapshots on development data,
report missingness and revision uncertainty, and distinguish activity contraction,
credit stress and named recessions. Predeclare evaluation windows and episode rules;
report false positives, missed episodes, lead/lag, state persistence, transition
frequency and stability by region and year. These are diagnostics, not a threshold
search against known recession dates or permission to inspect the retrospective holdout.

Persistence should retain complete immutable snapshots and configuration versions,
including UNKNOWN states and reasons. A richer UI can show eight pillars, evidence
age/quality/admission, structured positive/negative drivers and drill-down provenance.
Unknown must have visual prominence; do not present evidence confidence as recession
probability. Market-regime outputs may be shown separately as context with no circular
dependency or state feedback. The current core does not build that UI or fit a model.

Calibrated risk research, if later justified, belongs to the separate V2 note. Full
dashboard and Macro Risk Gate work follow a credible standalone DCA evidence result,
human scope approval and appropriate untouched evaluation; no automatic policy link.
